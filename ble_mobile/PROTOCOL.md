# 移动 BLE 半合成定位协议

## 验收口径

《HarmonyOS难题发布-第七期》第 1 页要求在所提供验证数据上，标准场景性能不劣化且移动目标检测精度提升 20%。页面没有给出“检测精度”的分母、命中阈值、基线实现或相对/绝对口径。本研究的预设替代指标是全部预定时刻中位置误差 ≤10 m 的比例，弃权计失败。相对提升为 `(S_KF - S_Cauchy) / S_Cauchy`，目标 ≥20%。同时报告百分点、≤5 m、≤30 m、WLS、Soft-L1 和短时保持最近一次 Cauchy 位置的基线。没有官方移动验证数据时，结果适用于本协议的回放。

## 数据与配对

复用两处静态实测 BLE 资料与冻结本地校准。按 `ble_crowd` 的校准、开发、验证、最终物理位置分区建立各自的路径图。A 为原始单秒记录，B 为源数据中每 30 秒保留的 5 秒 RSSI 汇总。合成时间轴独立于源数据采集时间，真实移动期间的 RSSI 演化、遮挡、时延和人体姿态未被测量。底层最终位置在历史静态实验中已出现，本阶段的轨迹与运动顺序首次锁定后评估。

每个节点使用该分区的真实目标坐标，最多连接距离 ≤12 m 的五个最近邻。路径为五个不同节点的相邻序列。平顺族的弦长/路径长 ≥0.68 且最大拐角 ≤100°，急转族最大拐角在 (100°,155°]、弦长/路径长 ≥0.33。每场地每族最多 12 条去重路径，固定种子排序并优先增加位置覆盖，每条路径使用三个确定性原始窗口重复。A 每条轨迹固定同一发射设备，B 使用单一源发射端。几何邻近构造不提供墙体和道路可达性保证。

| 场景 | 合成操作 |
| --- | --- |
| 匀速 | 平顺族，每段速率 0.85 m/s，按测点间距离定时，方向可随路段改变 |
| 变速 | 同一路径和原始窗口，四段速度依次为 0.45、0.65、1.25、1.50 m/s |
| 停走 | 第三个点加入两个 4 秒停留采样，使用同点不同原始窗 |
| 急转 | 急转族，路段速率 0.85 m/s |
| 稀疏 | 平顺族中第 2、4、5 帧最多保留两条原本存在的接收记录 |
| 连续缺测 | 平顺族末次观测前连续遮蔽 2 或 3 帧，随后恢复原始 RSSI |

任一保留移动 RSSI 等于源记录对应值。方法输入仅为当前时间戳、接收端坐标、RSSI、冻结模型及过去状态。路线、位置真值、稀疏/缺测标签和未来窗口只用于构造与评价。

静态回归用旧实测分区中同一位置、同发射端的 4–8 个有序真实窗，统一设置 4 秒回放间隔，检验同一自动滤波器在固定位置的行为。附加四个旧压力场景 `coord5 / joint / drop50 / one-sided`，沿用其扰动实现和六端资格，实测原始回放为标准场景。对外部已声明静止的业务模式另检查逐帧透传冻结 Cauchy 的结果。

## 方法和门槛

WLS、Cauchy+MAD 和 Soft-L1+MAD 为当前帧冻结解。基本 CV Kalman 的状态为 `[x,y,vx,vy]`，由真实回放时间差传播，使用 Cauchy 输出作为位置观测。过程噪声谱密度 0.10 m²/s³，位置观测标准差 3.5 m，初始速度标准差 1 m/s。缺测时仅在距离上次观测 ≤12 秒且最大位置轴标准差 ≤9 m 时输出预测。新观测可纠正状态，超出时效后新观测重初始化。预测协方差为经验模型量。短时保持基线沿用同一 12 秒上限，速度取零。

Agent 从开发结果优先检查自动静态回归、可能可恢复的过期缺测、转弯/变速/停走失败和异常创新，按固定规则每轮提一个预登记机制，最多四轮。独立 verifier 在配对验证帧上要求相对父方案总体成功率@10m 增加至少 0.5 个百分点，每类场景覆盖率和成功率下降不超过 5 个百分点、CEP90 恶化不超过 20%。两场地原始静态回放均须通过自动模式保护门槛：覆盖率不降，成功率@10/30m 最多下降 1 个百分点，CEP90 最多增加 max(0.25 m, 5%)。实际变化单列，业务声明静止时另以逐帧相等验证。阈值是本研究的操作定义。

方法和裁决先锁定，再生成最终轨迹。总体指标对场地×场景等权，同组各轨迹等权，再对轨迹内时刻等权。CEP50/90 条件于输出。连续性包含最长连续输出/成功片段占比、相邻输出和完整轨迹比例。更新间隔按相邻输出时间戳统计，同时报告输出位置距最后一次真实定位修正的年龄。间隔描述合成时间轴。

## 运行

```powershell
python -m ble_crowd.verify_freeze
python -m ble_mobile.run research ble_mobile/runs/reproduction
python -m ble_mobile.run final ble_mobile/runs/reproduction
python -m ble_mobile.review ble_mobile/runs/reproduction
```

从仓库根目录运行，选用新输出目录。实验数据和逐帧结果以压缩 JSON 保存。
