# Adaptive Tracking 冻结实验协议

## 数据和主指标

使用 `mobile-001` 已有开发、验证与最终轨迹，位置分区、原始 RSSI、合成时钟、遮蔽和校准原样保留。前两组用于研究和排序。先锁定候选、裁决和配置，再对已有留出轨迹做一次最终比较。此前已公开同一留出集的基线结果，本轮新增方案沿用物理位置留出，适用范围是两处固定设施的半合成轨迹回放。

沿用每个场地×场景等权、组内轨迹等权、轨迹内时刻等权。主要结果为全部时刻的 10 m 成功率，弃权计失败。相对提升以冻结 Cauchy+MAD 为分母，目标为 20%。窗口 WLS、Cauchy+MAD、Soft-L1+MAD、原冻结 18 s Kalman 和 12 s 保持均原样重放。辅助指标为 CEP50/90、覆盖率、连续性、更新间隔、距最近完整定位的年龄。

## 策略族

使用最近三个完整定位的时间与位置，按两段位移、速率和夹角判定静止、匀速、变速、转向或证据不足。近邻且位移小优先判静止，较大方向变化判转向，方向相近时以速率差区分匀速和变速。证据不足保留 unknown。状态是历史观测推断，方法只读取当前和过去公开观测。

1. 完整观测到达时更新原 CV Kalman。几何支持较强且发生转向或变速时可以直接输出当前完整解。质量量来自按 RSSI 距离误差标准化的局部距离 Jacobian 与残差。
2. 缺完整定位时，有一致速度证据且预测协方差足够小时输出 CV 预测。否则尝试保持最近完整位置。保持的不确定性随年龄、最近定位质量与估计运动状态增长。所有历史输出受 18 s 硬时效和 9 m 经验位置尺度上限约束，初始保持期限 12 s。
3. 候选机制包括在先验上使用一到两条真实距离的受限修正、在相同尺度上限下将保持期限放至 18 s、以及可靠当前解的大创新直出。稀疏修正用线性化距离、创新和位移门限及后验最大轴尺度控制，最近完整定位的年龄继续累计。显式静止业务模式逐帧走冻结 Cauchy。

## 研究顺序和裁决

最多四轮。规则式 proposer 首先针对开发集上保持与 CV 的覆盖差提出混合策略，再按开发集可回查的失败机会选择一个未试机制。独立 verifier 沿用 `ble_mobile.verifier`，父方案对比要求验证集成功率@10m 增加至少 0.50 个百分点，同时通过原移动分场景门槛及原自动静态保护门槛。两处原始静态回放覆盖率不得下降，10 m 和 30 m 成功率下降最多 1 个百分点，CEP90 增幅不超过 max(0.25 m, 5%)。其余静态压力场景继续报告。

最终 Adaptive 比较项按验证集成功率、CEP90 依次排序，优先取 verifier 接受且静态安全者。若无通过者，保留验证比较项及拒绝记录。最终建议法在通过验证静态保护的已接受 Adaptive、冻结 CV、保持和 Cauchy 间按同一顺序选定。最终集只报告锁定方案是否达到目标及静态门槛。已有窗口法仍作为显式静止回退。

## 执行

```powershell
python -m pytest ble_mobile/adaptive/test_adaptive_tracker.py -q
python -m ble_mobile.adaptive.run research ble_mobile/runs/adaptive-reproduction
python -m ble_mobile.adaptive.run final ble_mobile/runs/adaptive-reproduction
python -m ble_mobile.adaptive.review ble_mobile/runs/adaptive-reproduction
```

从仓库根目录执行。研究使用新输出目录。最终执行先写入一次性标记。复核读取结果及锁定来源。
