# 众包 BLE 静态实测协议

题目来源为老师发的《HarmonyOS难题发布-第七期》第 1 页“难题1：基于非线性优化的众包离线高精度位置聚合难题”。源文件 SHA-256 为 `ec52aee8742f8fbe92973ba0360bb2388acbb41e09a779305ced655c4b61f8b6`。

## 原题与本次口径

| 项目 | 原题明确内容 | 本次实地操作定义 |
|---|---|---|
| 上报设备 | 附近好心人设备扫描目标 BLE 广播并上报位置 | 每台实际到场且登记的独立手机一个编号。目标设备单列。同一手机的重复包和外接模块均归原手机 |
| 数量 | 原文为“10个以上好心人” | 按本轮指示每次安排至少11台独立手机，并报告实际有效上报数 ≥10 和 ≥11 两个分母。11 台是本轮操作门槛 |
| 定位输入 | 上报位置、BLE RSSI。题目说明权重可用定位时间、定位方式、精度、置信度等决定 | 记录手机编号、安装 UUID、型号、系统、经纬度、位置精度、定位提供者、RSSI、时间戳和目标 UUID |
| 真实目标位置 | 目标是估计丢失设备二维坐标，原题页示意了真实位置 | 由独立测量人员登记目标标记的 WGS84 位置、测量方法及不确定度。每次试验的手机摆位也独立测绘 |
| 静态精度 | 原文为“CEP90 30米以内” | 在符合人数的测试试验中报告有输出 CEP90，同时公布输出覆盖率和无输出计失败的总体成功率。原题页未规定分位估计与弃权处理细节 |

移动目标检测精度提升 20% 是原题的另一项要求，本次阶段仅执行静态协议。公开题目页没有固定真值测绘仪器、扫描窗长、测试样本数和详细验收数据格式。

## 现场执行

1. 登记至少11台不同的上报手机，建议准备13–15台以覆盖掉线，以及1台单独的目标设备。用实物标签 P01、P02 等核对实体，保存安装 UUID、手机型号、Android 版本及人员核对记录。卸载重装会产生新安装标识，需在开始前完成登记。UUID 只能协助查重，实体独立性由现场核对。
2. 选允许测量的较大室外或室内外混合区域。场地应使固定中心基线存在超过30米的真实误差，包含不同方向、距离和遮挡。记录目标硬件、发射配置、摆放高度、环境、现场布置。随机目标 UUID 固定用于整个活动，目标广播保持同一设备及发射配置。手机位置误差由其自身定位产生。
3. 用 RTK、全站仪或有控制点的独立测量获得目标与各手机的水平 WGS84 参考坐标。单独保存原始测绘记录、坐标转换、设备高度及水平不确定度定义。手机停在对应标记处，目标固定。手机系统报告的精度是独立字段，由定位服务估计，用于与实测误差比较。
4. 首次现场试运行使用独立活动编号。检查扫描权限、蓝牙广播、定位权限、实际时钟和离线导出。全员使用自动时间，对照同一 UTC 时钟检查偏差，记录检查值。应用用单调时钟给包与位置打时间戳，设备间同步由现场检查。
5. 正式采集前登记全部预定试验及划分。建议校准12、开发6、验证8、最终测试至少20个不同的目标物理位置。每个位置可重复2个窗。同一位置及所有重复永远留在同一分区。各窗至少安排11台实体手机。先安排分散布局，再在预先选定的位置改变布局，记录 `layout_id`。人数对照优先安排不同的实际手机数，且均保留不少于11台。所有分区应覆盖预定场地与布局，避免按结果分配。
6. 每个窗推荐30秒。提前约30–60秒发放同一采集票，先启动目标广播，再由各手机点击“准备采集”。手机保持原位、应用保持前台和屏幕亮起。到时自动保存。手机未收到包、没取得定位、离开前台或导出缺失均保留原试验。补采使用新预定试验 ID，保留原记录与原因。
7. 汇总离线 JSON 到数据管理员的私有目录。独立人员维护测绘真值和试验排程。定位研究先导入校准、开发、验证数据，锁定候选后交付测试数据。真值和经纬度留在私有目录，公开仓库上传代码、协议和合适粒度的汇总。

## 输入形成与评估

- 每台手机每窗形成至多一条上报。只接受票内的目标包，使用包到达时最新且年龄≤5秒、非模拟且精度有效的定位。取配对 RSSI、局部东/北坐标和精度各自的中位数。记录 RSSI 可见手机数和具备可用坐标的手机数。过晚启动超过2秒、提前结束或本机时钟漂移超过1秒的窗保留为失败。位置精度大小不作为事后筛选依据。
- 经纬度按 WGS84 投影到同一局部东/北坐标系，位置误差为二维米制距离。测试方案不改变原题30米条件。CEP90按物理位置等权，位置内各窗等权。计算输出条件 CEP90、覆盖率和 5/10/30 米总体成功率。人数门槛组报告组内覆盖，也报告全体预定窗中同时满足人数和30米的比例。
- 预定方法为报告坐标中心、WLS、冻结 Cauchy+MAD。中心使用有上报手机的位置，至少1条可输出。测距求解至少3条，优化失败记无输出。比较固定先验、统一校准、逐手机截距加共享斜率。校准只使用校准分区独立测绘的距离及真实 RSSI。每手机至少3个校准位置才拟合专属截距，稀疏手机共享截距。校准不可辨识或斜率非负时保留可用的简单模型。主模型优先顺序为逐手机、统一、固定，所有可用方案均报告。
- 系统定位精度值只用于本轮误差诊断。用同一组 RSSI 和冻结方法，把上报位置换成独立测绘的手机位置，形成独立标注的离线诊断对照。它量化同一组输入中的坐标替换影响，不作为部署方法。按实测坐标误差、几何、手机数量、布置与型号报告差异。型号残差还受距离、遮挡和姿态影响。
- Agent 从实际开发与验证结果调用既有 proposer。每轮单一机制，独立进程调用 verifier，限定在≥11有效手机的成对验证试验。沿用跨场地阶段的 2% 条件 CEP90 改善、场景尾部与覆盖保护。保留失去输出和最差误差增加的案例。无成对证据时保留冻结方法。根据验证结果锁定校准模型、配置和代码，之后才执行最终测试。
- 合成夹具的证据类型固定为 `synthetic_fixture`，仅测试软件。只有实际到场、实物登记及独立测绘的活动可登记为 `field`。该标签属于现场人员声明，程序通过数据检查与复放核对一致性。
