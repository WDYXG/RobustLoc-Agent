# Phase 3B.2 执行报告：联合 nuisance 可辨识性与最小信任

日期：2026-10-03。代码：`v3c/trust_agent`。本报告在冻结实验后写入 runs，未修改冻结策略、配置、评价器或任何既有 run。

本阶段已完成一个可运行、可审计的条件恢复原型，证明了指定模型下的可辨识性与覆盖界，保留了精确反例和实际失败。**没有解决一般物理最小信任问题，也没有建立能从消息自身验证物理信任的协议。**

## 数学对象与结论

研究联合世界 w=(x,p,污染支持,失实来源组)。名义 anchor 坐标只是元数据；物理约束来自显式外部参考、可信内部 baseline，或在来源预算下保留的断言。连续可行 target 集合是这些世界的投影，不能用几个预测布局的点云代替。

特别澄清：一个可信点消除独立平移，却仍允许围绕该点转动；标量 anchor–anchor baseline 保留整体 rigid gauge，单独不能建立绝对坐标。三个点固定 frame 与 target 可辨识是两个条件。

## 来源预算与 Agent 决策

q 计数单条 range 坐标，r 计数整个注册故障域。一个故障域可以发许多断言、使用许多名字；三个别名不构成三个独立来源。注册表、物理独立性、q/r 上限、外部 root 的真实性、D 覆盖和噪声上限仍属于外部前提。

Agent 枚举所有可能丢弃的来源组；只允许用精确不相交球证明删除不可能分支，禁止把优化失败当成分支不可行。有效候选的残差与几何界由独立 consumer 检查。普通 ranges 的有限预测值不参与授权；真实服务回复到达后，连续世界覆盖才能授权。

诊断分为：有经验证的世界对才输出 structural ambiguity；相同精确参考模型已有正 margin、但误差界不足时输出 precision/certificate gap；其他情况保留 unresolved。所有来源分支均矛盾时可以反驳所声明前提的合取，却不能据此识别哪一个来源说谎。

完整精确布局报告在诚实时一致、最多 r 个独立来源组失实时，2r+1 给出多数冗余。r=1 的 2/3 来源和 r=2 的 4/5 来源探针均执行，并在补充检查中独立消费正覆盖。这是已有错误纠正机制的模型实例，不是把 Byzantine agreement 的 3r+1 阈值搬过来。

## 固定实验结果

主 run：`trust-identifiability-001`；独立复现：`trust-identifiability-reproduce-001`。共 48 个物理实例 × 3 方法 = 144 个方法实验，其中每方法 44 个契约内实例、4 个故意违反来源预算的实例。开发种子与 held-out 种子不同，实验前冻结源文件、配置和种子，评价后未调参。

| 方法 | 契约内输出 | 新增认证 | 总信息成本 | 新增认证 / 成本 | 错误输出 / 界违例 |
|---|---:|---:|---:|---:|---:|
| 只买 range | 8/44 | 4 | 27.0 | 0.1481 | 0 / 0 |
| 随机买信息 | 30/44 | 26 | 123.9 | 0.2098 | 0 / 0 |
| 信任驱动 | 32/44 | 28 | 64.6 | 0.4334 | 0 / 0 |

在两来源平移歧义场景中，独立第三来源的报价 0.6 足以恢复条件认证；新 range 不能固定坐标。在无参考场景中，当前菜单的充分组合是三个绝对参考，成本 3.6。在精度不足场景中，三种方法均只需增加报价 0.25 的测距包。q=1 场景可通过三个参考位置加重复测距提供坐标冗余，不能将其解读为处理持续恶意 reporter 的保证。

故意违反来源预算的实例实际有两个失实组，却声明 r=1。每方法 4 次错误认证，总计 **12 次错误输出及界违例**，全部保留。真实世界不属于声明契约时，条件数学仍可通过；多数一致、hash 与 receipt 不能证明它们自身的物理故障预算。这与契约内 0 违例分开报告。

## 重要漏认证：生成器不完整

评价后仅在开发种子上做补充诊断，没有改变冻结代码、策略或 held-out 结果。记录在 `supplementary/results.json`，可执行脚本为 `supplementary_checks.py`。

bounded-reference 场景买入 a0、a1、a2 三个精确参考后，当前生成器仍使用所有被支持的测距，其充分半径预界约 0.243，大于目标 0.1。忽略另外三个仍有不确定性的参考，只使用这三个精确参考，则成本 **3.6**，输出半径上界 **0.0113323**。该替代证书直接通过针对原始全部观测的独立 consumer，而不只是通过删减问题的检查。

因此 refuted：**“当前生成器未认证，就不存在有效证书或缺少物理可信信息。”** 可行集合随真实信息增加而缩小，不意味着这个保守生成器给出的数值界也会单调改善。本次 32/44 输出包含真实的漏认证；不把它们全部归因于结构不可能。当前有限 minimum 只相对于已实现的预检查，不能冒充全局物理最小信任。

该补充脚本首次因把 offers 的 anchors 数组误写成 anchor 字段而失败，错误和源 hash 保存在 `supplementary-attempt1.json`，修正后成功。该失败未涉及或修改冻结 Agent。

## 审计与可复现性

- 全项目测试：**113 passed**，其中新增范围 31 项。
- 原有 **2,855 个 tracked 文件**逐字节未变；冻结基线 `1ed4e01`。
- 主 run 与复现均审计通过：463 条 hash-linked 事件、144 个几何证书、82 次条件输出覆盖、280 个结构世界对、76 个完整有限成本枚举、5 个精确反例。
- 82 次条件输出包含 12 次契约外错误输出；consumer 验证的是条件覆盖，不是物理前提真实。
- 两次 run 的 **395 个非运行时间文件逐字节一致**；仅排除 completion.json 与依赖其时间内容的 output_hashes.json。
- 实際 CLI 执行与检查保存在 `cli-preview/`；复现摘要和 Python/库版本在 `reproduction_verification.json`。
- 独立 consumer 验证来源分支完整性、几何证书、残差、覆盖算术、世界对可行性和成本枚举。有限预测的 safe 标签来自冻结生成器；完整成本审计依赖这些标签，不是另一个独立完备规划器。

## 尚未解决的边界

模拟外部仪器不是真实 GNSS、签名认证或校准协议。root 失实、故障域注册错误、q/r 超限不能由本系统自证不存在。未来购买的 ranges 在本实验中是干净的，只有 q=1 场景的初始一条 range 被污染。服务结果确定、候选预测布局有限，信息成本不包含计算时间；数值候选搜索不完备。

正覆盖有意忽略 baseline 等额外约束，故可能过于保守。一般测量图、联合 nuisance 的精确可行集、含不一致诚实误差的多数融合，以及一般最小外部信任仍未完成。研究循环是固定任务、项目内证明、精确反例、实验和审计构成的可运行循环，不能宣称已具备自主 LLM 定理发现能力。

下一项值得研究的是：**区分物理不可辨识、证书保守和搜索不完整，并为特定信息菜单建立信任成本下界。** 补充漏认证已提供一个具体问题；继续提高 coverage 本身不能回答这个问题。
