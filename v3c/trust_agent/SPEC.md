# Phase 3B.2 — Certifiable Recovery under Untrusted Nuisance Information

Inputs: nominal coordinate metadata, rational range observations with anchor ids,
hard externally assumed point/ball references, potentially false grouped layout
assertions, a failure-domain registry, trusted intrinsic baselines, q range and
r source-group budgets, clean norm E, trusted D, tolerance, offers/cost/budget,
finite forecast coordinate outcomes. Nominal metadata and receipt names alone
are not physical constraints. Hard trust is an explicit modeling assumption.

Positive recovery covers continuous worlds under the actual delivered references
and source-budget union. Source-group branches are all enumerated. Only exact
pairwise disjoint-ball certificates can delete branches. Optimization failure
cannot. Branch covers use independently verified frozen v3b bounds and nominal
residual feasibility. All possible branch covers must fit the reported radius.
Negative structural diagnoses require exact feasible worlds and sparse-map
equality. A loose bound without a witness is unresolved. Exact-reference positive
margin without a sufficient noise bound is a precision/certificate gap.

Two corruption levels differ: q counts individual range coordinates (repeats
can add redundancy); r counts whole registered premise failure groups. The
trusted group registry and global q/r limits apply also to future purchases.
Three aliases of the same instrument do not provide three independent groups.
The declared q/r bound is not inferred from residuals or majority agreement.

Actions: ordinary range repeats, trusted intrinsic baseline, absolute reference
query, or independent registered source report. Baselines preserve absolute
rigid gauge. Source reports remain potentially dishonest but can add redundancy
under r. Absolute query replies invoke an external physical trust root; binding
checks do not establish root truth. Replan only after actual replies.

The trust frontier enumerates all affordable bundles and checks a sufficient
common-branch-model geometry pre-gate across all declared finite forecast
layouts. Forecasts proved inconsistent with the declared source budget are
excluded; unresolved forecasts remain. It chooses the cheapest certified bundle,
acquiring trust first during witnessed structural ambiguity. This is a minimum
of a conservative certificate over a finite forecast menu, not a universal
minimum trust cardinality or an optimal stochastic/adaptive policy. Forecasts
contain anchor positions but no true target, true bad labels or future ranges.
After delivery, actual continuous certificates authorize output; forecasts never
authorize recovery. All source branches remain represented even if forecasts
do not enumerate the actual world.

Fixed comparisons: range-only, random-information, trust-directed. Retain
structural witness diameters, continuous cover diameter upper bounds, pre/post
source branches, actual cost/action mixes, risk, abstention and out-of-contract
stress. Infinite/unbounded conclusions are theoretical statements for unbounded
D; evaluated D is bounded. Hierarchy diagram uses an exact q=0 star example,
not a sampled finite-cloud diameter. The analytic zero/one/two/three-reference
diameters and the separate nonrigid star counterexample are both retained.

Development and held-out seeds differ; config/source/evaluator are frozen before
final evaluation. Never tune after held-out. Reproduce in a new folder and check
prior byte hashes. No new estimator optimization, phase retrieval or Codex
research-generation layer in this phase.
