# 本轮完成了什么，尚差什么

**静态求解流程与可复现实验已完成；原题真实 BLE 达标尚未完成。** 当前发布运行是 `runs/static-003`。它是记录快照修正后的同配置复放，不是增加了一批独立测试样本。

## 精度：有条件达标，不能笼统说已解决

最终集5,280例，每例成对比较4种方法。其中严格 n>10 的距离代理3,240例、合成RSSI 720例；n=8另外保留为对照。

|n>10 测试条件|最终方案 CEP90|WLS CEP90|最终方案 >30米失败率|
|---|---:|---:|---:|
|合成距离代理（全部预注册几何/噪声/异常比例）|24.09米|40.53米|5.96%|
|合成 RSSI（匹配与失配各半）|86.06米|62.28米|42.78%|

距离代理按设备数汇总：n=11 为 **28.59米**，n=16 为 **24.09米**，n=32 为 **18.32米**。这些汇总均低于30米，但并非每个子场景达标；n>10全部99个测试单元中只有73个点估计达标。每单元40例，不能当作精确总体尾部分位数。

RSSI分组：生成与反演传播系数均为2时，360例 CEP90 **20.84米**；生成系数2.8、反演仍用2时，360例 CEP90 **107.02米**，失败率 **82.78%**。这里的“匹配”是合成配置给定，不是完成了现场校准。结果支持“模型失配是当前明显失败来源”，不支持“增加 reporter 即能消除系统偏差”。

完整结果：[逐场景报告](runs/static-003/REPORT.md)、[每单元指标与区间](runs/static-003/study/strata.csv)。距离代理低于30米，不代表真实 BLE 达到原题指标。

## Agent 与运行时分别做了什么

已有规则型研究 Agent 在新开发/验证集上依次检查阈值、去除不确定性权重、多起点。三项均被独立 verifier 拒绝，最终保留旧 Cauchy+MAD。没有夸称“本轮 Agent 提出了更好的新算法”；其实际贡献是执行可审计的迁移检查并阻止退化方案进入最终流程。保存的失败解释仍是实验解释，不是定理。

应用层复用旧估计器和有界恢复器，接通输入检查、RSSI适配、估计、条件认证、拒绝与信息请求。普通 Gaussian 标准差没有硬上界，主实验可靠出口全数未认证；数值估计仍全部计入 CEP90。

独立受控契约实验：有效契约36例，12例获得认证，0例违反误差界；24例未认证。把物理 reporter 和目标共同平移60米、却不改报告坐标的失配组，同样12例被认证，但12例全是错误输出。这是外部误差契约失真的失败，不是已解决的可信性检测。

主动信息示例从11个近共线 reporter 开始，实际执行3次仿真信息获取后，q=1 几何下界从0升到0.23158，n=14时认证成功，误差0.0106米。它证明这条工程闭环真实执行，不证明一般主动策略收益，也不代表真实设备扫描。

## 结论边界与下一步

目前可以交付并复现静态研究原型，也可以清楚展示何时失败。尚不能交付“已在真实众包 BLE 上达到30米”的结论。

下一步若继续原题求解，应集中于**取得米制真实数据及独立RSSI校准，检验传播失配下的模型/损失函数**。需要重新划分开发和最终测试集；不能根据本轮最终结果反选参数后继续称其为原来的 held-out 成绩。无需再增加逆问题或版本分支。

其他限制：近共线合成布局围绕目标生成，未穷尽目标离开 anchor 直线后的镜像歧义；异常机制仅覆盖一种联合坐标/测距污染；同组分位数混合场景，区间未做多重比较校正；没有经纬度投影、真实设备扫描或移动目标检测。新增实验结论统一为 **numerically-supported**，真实部署性能仍 **unresolved**。
