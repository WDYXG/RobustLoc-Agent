# 数据与来源

`iBeacon_RSSI_Labeled.csv` 与 `iBeacon_Layout.jpg` 原样取自：
https://archive.ics.uci.edu/static/public/435/ble%2Brssi%2Bdataset%2Bfor%2Bindoor%2Blocalization%2Band%2Bnavigation.zip

引用：Mohammadi, M. & Al-Fuqaha, A. (2017). BLE RSSI Dataset for Indoor localization and Navigation. UCI Machine Learning Repository. DOI https://doi.org/10.24432/C54G80 。许可 CC BY 4.0：https://creativecommons.org/licenses/by/4.0/ 。本目录保存的两个文件未修改。

数据说明：https://archive.ics.uci.edu/dataset/435/ble-rssi-dataset-for-indoor-localization-and-navigation 。缺测值 -200。部署13个信标并不意味着每个样本观察到13个；本项目核查每条实际可见数量。无可靠米制比例，不编造坐标尺度。

`source-page1.png` 是用户工作区所给 HarmonyOS难题发布-第七期.pdf 第1页的审查渲染，非本项目创作。用于核对指标，不作为定位数据。原PDF路径在工作区 `可参考的问题/`。权利归原发布者；Git提交不分发该渲染图，仅记录其来源与核验结论。
