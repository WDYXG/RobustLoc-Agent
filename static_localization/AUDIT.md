# 现状审查与最小改动

审查基线：`8705679`，历史 4,783 个文件保存于 `PREVIOUS_FREEZE.json`。

| 已有能力 | 本轮复用 | 原先的缺口 |
|---|---|---|
| v1 Observation、LS/WLS、Cauchy、MAD、多起点 | 直接调用冻结代码 | 无面向原题 n>10/30米的独立米制验证 |
| v1 proposer 与独立 verifier | 三轮有限迁移检查，保存拒绝结果 | 根 agent 入口会改旧配置，故新增隔离运行入口 |
| v2/v3b 几何与位置误差证书 | 对当前估计做残差及域检查，独立复核 | 标准差不能自动充当硬界；复杂度需限额 |
| v3 系列恢复/拒绝/信息获取 | 接入统一输出，执行一条新增 reporter 轨迹 | 不能把多个独立旧实验描述成原题端到端应用 |
| v4/v5 跨问题与自主研究 | 保留历史证据，不开展新分支 | 本轮不重新训练/搭建 Agent |
| final_acceptance | 保留旧记录 | 原设置初始最多6个设备、新增后最多9个；0.5米阈值与本轮题标不等价 |

新增 `service.py`：输入白名单、唯一 reporter 身份、米制坐标、距离/RSSI反演、复用求解器、独立证书出口。正常位置误差、正常测距误差和异常值独立记录。RSSI 适配只实现参数已给定的 log-distance 反演，不宣称已完成真实 BLE 校准。

新增 `simulation.py/study.py`：新开发、验证、最终种子分区；先冻结选定方法，再生成最终集；保存观测/私有评价数据、全部误差、三轮研究状态和 verifier 结果。不改旧评价器；30米指标在新应用评价器实现。

新增 `reliability.py`：用原精确内核认证当前最终方案的实际输出；不预先把真实目标塞给 decoder。有效/失配契约并列、实际执行的仿真信息请求并列。其小噪声条件不能替代主实验中的Gaussian噪声。

原题第1页已视觉核验。静态30米目标得到来源支持；没有获得原题指定验证数据。公开UCI数据已下载并审查，不能据此声称已完成米制实测。
