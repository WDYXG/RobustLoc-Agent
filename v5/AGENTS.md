# Phase 5 execution boundary

Everything tracked at 1440f9c is immutable; PREVIOUS_FREEZE.json binds 4,083 files.
All new work belongs to v5/. Do not edit historical reports, core, or ledgers.
Before a scientific run freeze v5/researcher, tests, protocol and source corpus.
After a run manifest exists, changes require a new evaluator version and run.

The proposer is untrusted. It emits one JSON proposal per iteration. Its text
never grants a status. Only the controller invokes the deterministic verifier
and appends ledger events. Failed calls and invalid proposals consume a round.
No scripted substitute may be labelled a Codex run. Replay is not regeneration.
Do not claim literature novelty or general theorem-proving from this prototype.
